Asterisk POC — ศูนย์บริการลูกค้า 1484 (เมืองไทยประกันภัย)

1. หน้าจอลูกค้า

keypad เท่านั้น — โทร 1484 ได้จริง (softphone SIP.js) หรือโหมดจำลอง รับสายโทรออกจากศูนย์ฯ ได้

2. หน้าจอ Agent

สถานะ พร้อม/พัก รับสาย พักสาย โอนสาย และปุ่มโทรออก

3. Dashboard

คิว agent สายสด เหตุการณ์สด เพิ่ม/ลบ agent ลูกค้าโทรพร้อมกัน

4. Transactions

ไทม์ไลน์ละเอียดของแต่ละสาย รวมถึงโอนสายจากใครไปที่ไหน

5. Flow Map

แผนภาพ: แต่ละขั้นตอน module ไหนคุยกับ module ไหน (สด)

6. API (Swagger)

REST / WebSocket สำหรับ CRM และ Agent application

ลองทำตามนี้ (ใช้ 2 แท็บ)

  1. แท็บ A: เปิด Dashboard → กด "+ เพิ่ม Agent" เพื่อสร้าง Agent ใหม่ (หรือกด "เปิด Demo mode" เพื่อใช้ agent จำลอง)
  2. แท็บ B: เปิด Agent → เลือก agent → กด "พร้อมรับสาย" (ต้องอนุญาตไมโครโฟน)
  3. แท็บ C: เปิด ลูกค้า → กด 1484 → โทร → ฟังเมนู IVR แล้วกด 1-6
  4. Agent รับสาย → พักสาย / โอนสายไปคิวอื่น → ดูไทม์ไลน์ที่ Transactions
  5. Agent กรอกเบอร์ลูกค้า (เช่น 0800000001 ที่เปิดหน้า "ลูกค้า" ไว้) → โทรออก → ลูกค้ากดรับ/ปฏิเสธ/ปล่อยให้ไม่รับ
