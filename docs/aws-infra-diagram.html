Risk Management

  • Blast radius: shared VPC with another service; nothing else changed
  • Data: lab/simulated calls only, no real customer data (confirm)
  • Time-box + owner + cost cap (~US$35/mo); destroy = one command
  • Lab-grade SIP passwords: never open SIP to 0.0.0.0/0

Security

  • Inbound only from allow-listed CIDRs (SIP/RTP UDP, SSH, API 8000)
  • Fixed: egress limited, SSM role, encrypted disk. Remaining: API plain HTTP (use SSH tunnel), no WAF/logging
  • IMDSv2 enforced; root volume encrypted; SSM Session Manager available
  • No public IP: access only over VPN (assign_eip=false)

Platform

  • Set subnet_id to the agreed subnet (variable added; default VPC only as fallback)
  • Tags via extra_tags, optional IAM permissions boundary, quotas
  • Terraform state location and who may apply in this account
  • Private ALB rule for API 8000 (alb_security_group_id); SIP/RTP UDP cannot use ALB, so VPN direct

  • Required tags, IAM role/permission boundary for deployer
  • Logging: VPC flow logs / CloudTrail / SSM instead of SSH?
